## 二、设计语言

- **底色**：近纯黑（#0D0D0D 级），卡片深灰（#1A1A1A 级），层次靠卡片分组而非分割线
- **强调色**：
  - 亮绿 —— 主按钮 / 选中态 / 正向数据（"已达标"） / 导航选中胶囊
  - 橙色 —— 体重数据卡（首页"最新体重"）/ 训练标记点 / 次强调按钮
  - 蓝色 —— 称重标记点（图例：训练·橙点，称重·蓝点）——注：实际截图中称重为蓝/绿色点，实现时统一取色板
- **卡片**：大圆角（约 16-20px）、内边距宽松、信息分组清晰
- **数字排版**：核心数字特大号加粗（体重 164.0），单位（斤）小号跟排
- **底部导航**：4 Tab，选中态为绿色胶囊高亮图标（非全宽指示条）

## 三、页面规格（按截图逐页整理）

### 3.1 主控页（04-dashboard.jpg）

自上而下：
1. **标题栏**："简瘦" + 右上角功能入口
2. **月历卡片**：当前月（可翻月），训练日橙点 / 称重日蓝点标记，今天绿色高亮（圆形底）
3. **最新体重卡**（橙色系，核心卡片）：
   - 头部：图标 + "最新体重" + BMI 徽章（如 26.8）
   - 主数字：`164.0 斤` + 记录日期（06月10日）
   - 底部三栏：`-1.0斤 累计减重` ｜ `48天后 预计达成` ｜ `距目标 140.0斤 还差 24.0斤`
4. **今日热量卡**：空态引导文案"今天还没有记录饮食 去饮食Tab记录"（点击跳饮食）
5. **今日饮水卡**：进度（如 1/8 杯）+ 进度条
6. **月度对比入口**：一行摘要（累计 -1.0斤 · 3天）
7. **本周周报入口**：一行摘要（训练 0 天）
8. **最近训练**：列表（空态时提示）
9. **交互反馈**：记录体重后底部 SnackBar 确认（"今日 164.0 斤 ✓"）

### 3.2 训练记录页（03-workout-log.jpg）

1. **标题栏**："训练记录" + 右侧四个入口图标（日历 / 统计图表 / 清单 / 筛选）
2. **周日期条**：
   - 顶部周范围（6月8日 - 6月14日）+ 左右切换 + 日历图标
   - 7 个日期小卡片（一~日）：日号 + 当日标记点；**选中日绿色描边高亮**
3. **当日标签**："今天"（绿色）+ 右上图例（训练·橙点 称重·蓝点）
4. **记录列表** / **空态**：拉伸人形图标 + "暂无训练记录" + 绿色"+ 开始训练"按钮
5. **FAB**：右下角绿色"+"大按钮

### 3.3 快速训练页（01-quick-workout.jpg）

1. **标题栏**："快速训练"
2. **节奏选择卡**（橙色调）：标题"选择节奏，马上开练"+ 副文案；三项数据（10分钟 / 5个部位 / 23个动作）×3 组节奏；按钮"自定义训练"
3. **推荐模板**区块（"选择一个节奏，立即进入训练"）——每张模板卡：
   - 图标（彩色）+ 模板名 + 难度标签（入门/中阶/高阶）+ 部位标签（全身/放松）+ 右侧大号时长（15 分钟）
   - 一句话描述
   - 动作预览行：动作名 × 组数（深蹲 3×15 ｜ 俯卧撑 3×10 ｜ 平板支撑 0min）+ "＋N个动作"
   - 底部：编辑图标 + **"开始训练"主按钮**（按钮颜色随难度/模板主题变化）
   - 示例模板：新手减脂15min / 燃脂训练20min / 高效HIIT15min / 办公室运动10min / 睡前拉伸10min
4. **我的模板**区块（"保存你常做的训练组合"）：用户自建模板（编辑 + 开始训练）
5. **这是当前代码缺失的功能**——训练模板系统（含推荐模板与自定义模板）

### 3.4 趋势页（02-trends.jpg）

1. **目标进度卡**（绿标题）："距离目标还差 24.0 斤" + 子文案（以 6月8日 165.0斤 为起始基准，已记录 3天）
   - 三宫格：`164.0斤 当前` ｜ `0天 锻炼日` ｜ `0张 照片`
2. **体重时间轴卡**：起点（6/8 165.0斤）→ 当前（6/10 164.0斤）→ 目标（140.0斤）三点连线
   - 下方两栏：`-1.0斤 距离起始` ｜ `还差 24.0斤 距离目标`
3. **体重趋势卡**：折线图（横轴日期区间），风格与现有 fl_chart 实现可复用
4. **身体照片卡**：入口（记录体重时可同时录入围度数据）
5. **你的变化故事卡**（绿色）：坚持天数 / 累计减重 / 鼓励语——情感化设计，减脂激励
6. **减脂效果分析卡**（绿竖条）：
   - 统计摘要（过去3天累计减重、锻炼次数）
   - 趋势判断（"体重呈现下降趋势……你的减脂策略有效"）
   - **预测**（"按当前趋势，预计 X月X日 达到目标体重（约 N 天后）"）
7. **本周概览**：体重变化 / 训练天数（0/7）/ 今日摄入
8. **入口列表**：周报 → 月度对比 → **减脂战报**（可分享的成果卡片：体重变化 + 照片）

## 四、开发路线影响

| 设计要素 | 落到哪一步 |
|---------|-----------|
| 首页重排（3.1 规格） | **Phase 2 首单"首页减脂仪表盘改版"直接按此实现**（含体重卡三栏、SnackBar 反馈） |
| 导航 5→4 Tab | 首页改版同期进行（主控/训练/趋势/我的；体重、饮食入口内化到各 Tab） |
| 训练模板系统（3.3） | 新功能——纳入 v2 路线（数据模型：模板表 + 模板动作表 + 推荐模板种子数据） |
| 趋势页（3.4） | 新建页面，整合现有周报/月对比 + 新增时间轴与效果分析 |
| 减脂战报（分享卡片） | v2 后期（依赖趋势页数据） |

> **实现注意**：
> 1. 截图中的数据（164斤/140斤目标/6月日期）为演示数据，不必照搬，逻辑按真实数据计算
> 2. 训练模板系统按现有分层规范新建 feature（`features/workout_template/`：data/domain/presentation）
